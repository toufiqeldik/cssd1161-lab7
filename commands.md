\# Five Essential Git Commands



1\. git init - Initializes a new Git repository.

2\. git add - Stages files for the next commit.

3\. git commit - Saves changes to the local repository.

4\. git status - Displays the current repository status.

5\. git log - Displays the commit history.

6\. git branch - Lists, creates, or deletes branches.

7\. git merge - Combines changes from different branches.
